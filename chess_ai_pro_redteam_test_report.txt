Chess AI Pro — Red Team regression report

Changes
- Restored the missing spHpForState(state, r, c, piece) helper. It was required by move generation and Worker initialization.
- Added a fallback move path for a live king in check when all ordinary legal responses are filtered out, including temporary stun/web lock handling.
- Made minimax/quiescence terminal scoring use king HP. A live king is not assigned a classical mate score. Simultaneous king destruction is scored as a draw.
- Corrected check-evaluation sign for the engine's black-positive score scale.
- Added early static combat-state evaluation for special actions and damage-only moves.
- Reworked ordinary-move HP/effect transfer and cleaned combat metadata attached to empty squares.
- Replaced false “mate in one” analysis messages and capped displayed loss labels for terminal scores.
- Updated game-end messages to show king destruction instead of “position needs repair”.
